Зона ответсвенности 



Разработка графического интерфейса (GUI):


Спроектирован и реализован клиентский интерфейс на базе библиотеки Java Swing с использованием паттерна MVC (Model-View-Controller).


Реализована система ввода SQL-запросов, а также выпадающий список (история) для быстрого доступа к ранее выполненным командам.


Написан алгоритм парсинга текстовых ответов от ядра СУБД и их динамическое отображение в таблице JTable (с автоматической сортировкой по ID).


Реализована обработка исключений (try-catch) на уровне интерфейса: любые ошибки бэкенда (неверный синтаксис, отсутствие таблицы) перехватываются и выводятся в панель статуса, предотвращая аварийное завершение программы.


Настроен стиль интерфейса (темная тема). Проведена интеграция GUI с классом SQLParse


Литература для GUI:


Oracle. The Java Tutorials: Trail: Creating a GUI With JFC/Swing. Официальное руководство по созданию графических интерфейсов. Содержит примеры создания окон, обработки событий и использования компонентов (JTable, JFrame, JButton).


Java Platform, Standard Edition 17 API Specification (Package javax.swing). Справочник по всем классам и методам библиотеки Swing, использованным в проекте (например, DefaultTableModel, BorderFactory).
